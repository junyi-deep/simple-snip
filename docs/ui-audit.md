# Simple Snip 界面审计

2026-11-19，审计基线 `316e74c`。应用常驻托盘，偏好设置是唯一主窗口。品牌沿用蓝色图标；偏好设置、编辑工具和系统菜单中的既有入口与快捷操作继续保留。

| 界面 | 实际入口与实现 | 问题 | 优先级与方向 |
| --- | --- | --- | --- |
| 偏好设置 | `settings.rs`，通用、截图与标注、贴图、长截图、GIF、文字识别、鼠标拖尾、快捷键、保存与历史、外观、关于 | 导航用实心主按钮；行的边框和辅助文字写死浅色；标题、表单、状态间缺少统一尺度 | P1：左对齐导航、主题化设置行，保留独立滚动及自动保存 |
| 历史与更新 | `settings.rs`，历史嵌入设置，更新进度和权限位于关于页 | 路径可能很长，控件和状态混用同一文字层级 | P1：文件名 / 路径分层，辅助状态和错误语义分开 |
| 截图 | `app.rs`、`overlay.rs`，全屏冻结、吸附、选区、放大镜、输入和标注 | 只在当前屏幕显示遮罩；工具栏使用固定深色与估算宽度；尺寸和取色信息重复 | P0：每屏覆盖，会话只允许一屏选区；统一选区轮廓、快捷提示及悬浮面板 |
| 原位标注 / OCR | `editor.rs`，截图和贴图共享画布、主工具条、属性行、文字输入、OCR 选择与提示 | 工具组边界不明显；面板与消息各自定义圆角和颜色；文字输入、选中控点及图像内容容易混淆 | P1：工具按用途分组，统一按钮反馈、选中轮廓和图片上文字对比度 |
| 贴图 | `pin.rs`、`editor.rs`，图片窗、右键菜单、独立随动工具栏 | 自定义高亮蓝与截图选区、编辑器不同；提示颜色与其它浮层不一致 | P1：闲置无附加控件，已选状态明确，保留用户边框和阴影配置 |
| 长截图 / GIF | `task_toolbar.rs`，区域边框和浮动面板，GIF 有独立预览 | 模式、尺寸、运行状态写在一行；按钮挤压时换行；不同阶段的提示同权重 | P1：形成状态栏和工具行，预览用中性图像背景，保留原有控制键 |
| 菜单、对话框、提示 | `app.rs`、`settings.rs`、`pin.rs` 与平台适配；系统托盘、权限及文件面板，GPUI Kit 右键菜单、通知和更新对话框 | 系统菜单绑定标签会与自定义快捷键不符；应用内浮层未共享配色 | P2：按系统规范保留系统界面；应用内菜单、通知、对话框用统一主题 |
| 彩虹拖尾 | `effects.rs` 与设置内的预览 | 彩色内容属于功能和用户参数 | 保留效果、色值与透明窗机制；统一设置外壳 |

审计依据为源代码和现有产品截图，未将历史截图视为这次运行验收。编辑文件前核对锁定包：`gpui-kit 0.8.0`、`gpui-component 0.8.0`、`gpui-base 0.8.0`、`gpui-pre 0.3.9`。基础控件继续用锁定版本的 `Button`、`Input`、`Switch`、`ColorPicker`、`PopupMenu`、`Progress` 与通知，不引入新库。
