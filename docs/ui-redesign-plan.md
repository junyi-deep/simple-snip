# UI 重构计划

1. **主题与通用控件。** `src/ui.rs` 提供颜色、排版、间距、面板和提示样式。通过锁定版 GPUI Kit 应用浅色和深色主题。先编译，然后用通用页核对导航、焦点、换行和自动保存。
2. **偏好设置。** `src/settings.rs` 将相同骨架应用到全部 11 个分类，整理历史与更新状态。保留控件 ID、配置订阅及写入时序。验收默认和最小尺寸，长路径、错误及进度可读，Tab 不被容器吞掉。
3. **多屏截图。** `src/app.rs` 与 `src/overlay.rs` 为每屏持有遮罩窗口，选区与焦点仍单一。空闲跨屏切换活动窗，选区形成后锁定，Esc/结束释放全部冻结图。回归验证跨屏、显示器缝隙、混合 DPI 和选择后不可切换。原生额外验证窗口首帧、焦点与高 DPI。
4. **画布与浮层。** `overlay.rs`、`editor.rs`、`pin.rs`、`task_toolbar.rs` 共用表面与画布控件。校验选区四边的工具条位置、贴图低干扰、OCR 选择位置、任务状态和预览。保持原始图像、标注数据、截图与录制处理规则不变。
5. **菜单与验收。** 校验 `app.rs` 菜单快捷键标签，系统对话框保留原生样式。执行格式化、编译、Clippy 和 workspace 测试。用实际 GPUI 窗口截图验证亮暗主题及小尺寸；无硬件或系统会话时记录覆盖范围。

执行记录：先完成审计与通用页试点，根据真实窗口截图调整导航为左对齐；随后迁移 11 个设置分类、截图遮罩、标注／OCR、贴图、长截图与 GIF。最小窗口检查后收紧过宽的主按钮，并用 Kit 的滚动条为长页面提供提示。框选复拍确认编辑图像不再超出选区。平台覆盖、构建与复现步骤见 [ui-visual-verification.md](ui-visual-verification.md)。
