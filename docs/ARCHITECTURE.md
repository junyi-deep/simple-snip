# 架构与关键决策

## Workspace

- `snip-core`：无原生窗口类型。图像坐标、非破坏标注与历史栈、配置、历史索引、OCR 结果与选择、拼接、GIF 时间戳 / 有界编码、拖尾生命周期。
- `snip-platform`：ScreenCapture / ClipboardProvider / OcrEngine 接口；XCap 原生截图、Arboard 系统剪贴板；独立 macOS 和 Windows 窗口、鼠标、滚动和 OCR 后端。
- 应用 `src/`：唯一 GUI 为 GPUI Kit。全局 Runtime / 命令通道、Overlay、独立 PinView、共用内嵌 EditorView、工具浮条、偏好设置与采集控制。

## 图像与编辑

屏幕采集在后台执行 → 每个显示器冻结图像 `Arc<RgbaImage>` → 对应全屏 Overlay → 框选后在同一 Overlay 内嵌标注画布。不会打开独立图像编辑框。

贴图的空格操作在原窗口内装入同一编辑组件。仅工具栏使用独立小浮窗，以免小贴图裁切工具栏；图片不迁移到另一个窗口。工具条与图片右下角对齐，屏幕下方空间不足时向内放在下边框上侧。位置算法有单元测试；截图在创建编辑器时直接传入选区的窗口逻辑 Bounds，实际布局变动通过下一轮事件更新，避免在 prepaint 中重入借用编辑实体。

Document.original 保留源像素；标注对象、颜色、线宽、撤销 / 重做独立保存。原始图像坐标与界面缩放分离。贴图翻转 / 旋转通过 ImageTransform 正反映射命中测试与 OCR 文字框，最终导出时合成和变换。文字字体按需在后台读取本机字体并共享缓存。重绘合并待处理请求，防止拖动时无限创建图像任务。OCR 任务和编辑会话使用独立 Cancellation，切换工具只取消 OCR。编辑器取消 / 释放使会话 Cancellation 失效；合成后、剪贴板写入后、原贴图事件提交时均检查，防止取消后的旧任务回写新会话。

## 任务与生命周期

- GPUI 前台仅处理状态和窗口；截图、OCR、合成 / 保存、拼接、GIF 在线程或后台 executor 执行。
- 命令通道容量 64；GIF 原始帧队列容量 3，过载丢帧并保留时间戳；采集、量化编码分线程，重复帧合并时累计时长。
- GIF 默认 15 FPS、最长 60 秒，用户可设 5/10/15/20/30 FPS、最长 600 秒；输入帧 / 输出帧有内存保护，流式写入 `.gif.part`，完成后更名。取消清理本任务临时文件；失败保留可恢复的已编码文件。
- GIF 控制栏录制时隐藏；从托盘暂停 / 继续、停止保存或取消。退出时取消注册任务，最长等待 3 秒。
- 长图峰值预算 256 MiB，失败保留已拼图像；支持手动逐帧、手动滚动监测和有次数上限的自动滚动。取消前和注入滚动前均检查任务状态。
- 默认只有 F1/F3 全局热键。其他动作初始不注册；热键替换失败回滚，退出注销。
- 原位贴图编辑可按 Tab 聚焦工具浮条；选择绘图工具后回到图像焦点，Esc 取消、空格完成并恢复原贴图焦点。均为局部操作，不新增全局热键。
- 偏好设置关闭使用隐藏并复用；QuitMode::Explicit 保留托盘运行，重新打开应用有设置入口。进程文件锁避免重复实例。

## 原生选择与风险

GPUI Kit 0.8.0 固定 gpui-pre 0.3.9；gpui-tray 0.3.0 关闭默认 backend，启用 gpui-kit + menu-state。`cargo tree -i gpui-pre` 验证只有同一个 0.3.9。

当前采集使用 XCap：macOS CoreGraphics、Windows 原生截图路径。GIF 当前是区域定时采集，而非已完成的 ScreenCaptureKit / WGC 持续视频管线。API 允许替换，不能据此声称专用流式采集已完成。

macOS 上实际遇到 AppKit Touch Bar KVO 崩溃（GPUI Kit #3192）。使用公开 NSResponder API 配置稳定的 NSTouchBar，并隐藏复用设置窗口，作为缓解措施；不屏蔽 Objective-C 异常、不 swizzle 系统方法。实际复测证明仅设置 Touch Bar provider 不足以规避。现使用 `window_pool`：macOS 关闭贴图、截图、采集控制和拖尾时隐藏原生窗口，替换为空 Root、缩至 1×1，并按窗口角色复用。图像 / 文档 / 后台任务随旧实体释放；空原生壳数量至多为各角色同时打开数量的历史峰值，不随截图次数增长。工具浮窗全局最多一个，切换贴图时释放上个编辑器。Windows 仍正常销毁窗口。原生测试验证同一窗口句柄复用与已关闭文档 WeakEntity 失效；短时 UI 链路已通过，长期稳定性仍待回归。

配置使用用户配置目录、serde + TOML、版本检查、v0 → v1 默认字段迁移与临时文件原子替换。损坏文件在读取时保留，UI 提示恢复默认。历史索引保留数量不删除用户已经导出的图片。

## macOS 全屏覆盖与回调

GPUI 的 `titlebar: None` 创建的是 titled + full-size-content 窗口，macOS 27 实测仍会将全屏窗口顶部约束到菜单栏下方，形成 30 逻辑像素偏移。`WindowStyle.desktop_overlay` 仅对全屏捕获 / 特效窗口启用真正的 borderless，并按显示器逻辑边界重新定位；贴图和交互工具浮窗保留 GPUI 原有样式，避免扩大焦点差异。

原生移动通过 dispatch2 0.3.1 的主队列异步提交，MainThreadBound 持有窗口，避免 AppKit 移动回调在 GPUI App 的 RefCell 借用期间重入。使用同一 objc2 0.6 绑定，不修改上游和系统方法。

## 0.1.1 权限、标注与特效修复

截图服务先检查系统预检；未确认时，在后台通过 ScreenCaptureKit 的 SCShareableContent 回调验证当前运行身份。仅系统 UserDeclined（-3801）映射为 ScreenPermissionDenied，其他服务失败 / 30 秒超时保留具体错误。主线程用 GPUI 的原生 prompt 显示系统消息框并防止重复弹出，确认后深链到录屏隐私设置。此流程不修改 TCC，不等同于完成 SCK 视频采集后端；XCap 仍负责像素采集。临时签名重建后的系统身份问题需要重新添加当前应用或有效正式签名，不能通过代码绕过。

标号是含编号文本的独立 Annotation 对象；按当前文档最大编号递增。ArrowStyle 使用 serde 默认值兼容旧对象；三种箭头都由共享的填充轮廓合成，选择框与导出复用几何边界。滚轮调整选中对象粗细，连续 250ms 内合并撤销快照。颜色、粗细、样式修改与源像素分离。

文字输入控件挂在图片位置上，下一帧安装后才交给键盘焦点；回车提交，空白既有文字可删除，Esc 只取消当前输入。工具提示跟随原位画布鼠标：原生箭头 / 十字 / I-beam 加独立工具图形，滤镜与橡皮显示随大小变化的圆形范围；这些界面提示不会导出。取消截图延迟到当前事件结束后替换根视图，避免同一窗口重入更新失败。

鼠标特效每个显示器独立全屏透明穿透窗；除原生透明背景外，显式将 Kit Root 背景覆盖为 alpha=0，创建和窗口池复用均执行。轨迹用 Catmull-Rom 转三次贝塞尔，时间透明度与双层光晕；不在采样端点叠加圆形，避免出现亮点。保留 256 点上限和静止降频，不新增系统热键。

## 首个公开版本 0.0.1：更新与连续拖尾

用户指定首个公开版本为 0.0.1，之前 0.1.x 是本机内部开发构建号。新增 snip-update Workspace crate：reqwest 0.13.5 blocking + native-tls + system-proxy，semver 比较稳定 Release。仅用户主动检查 / 下载时联网，不发送截图、剪贴板或 OCR。所有网络工作在后台线程，检查响应上限 2MiB，下载上限 256MiB，有连接 / 总超时、进度与原子临时文件。按目标选择 DMG / ZIP，初始下载地址必须属于本仓库 GitHub Release，HTTPS 校验证书，下载后比对同一 Release 的 SHA256SUMS；校验失败不保留可安装文件。

代理配置持久化模式、地址与用户名；密码为遮罩的会话字段，不序列化、不写日志。默认使用 reqwest 的系统代理（系统设置 / 环境变量；不包含自定义 PAC 脚本执行器），可直连或指定 HTTP(S) 代理并使用可选 Basic 认证。HTTP 代理可通过 CONNECT 转发 HTTPS，TLS 不降级。校验包下载完后在文件夹显示，用户退出并替换安装；没有静默覆盖正在运行的程序，正式签名更新机制仍待后续证书支持。

拖尾改成贝塞尔曲线细分的共享边带状几何，相邻位置复用位置、法线、时间和宽度，两端 GPU 线性渐变同时插值颜色和透明度；不再为每段刷一个不变颜色。每曲线最多 64 段，点缓存仍为 256，避免无限增长。生命周期 100–3000ms 可设置，保存后重新应用，无需先关闭特效。
