# Simple Snip 原生设计系统

使用冷调灰、蓝色和系统字体。设计取值 `DESIGN_VARIANCE: 5`、`MOTION_INTENSITY: 2`、`VISUAL_DENSITY: 6`。应用内渲染采用 GPUI；系统托盘、权限、文件选择保持系统外观。应用图标不变。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 背景 | `F8F9FC` | `191D24` | 设置内容背景 |
| 导航 | `EEF1F6` | `151920` | 设置侧栏 |
| 表面 | `FDFEFF` | `222832` | 控件及浮层 |
| 正文 | `202938` | `EEF2F8` | 标题、控件文字 |
| 辅助文字 | `505E71` | `AAB8CC` | 说明、路径、状态 |
| 分隔线 | `D7DFEA` | `3B4657` | 区域边界 |
| 主按钮 | `275FC2` | `91B7FF` | 显式确认、焦点强调 |
| 选中背景 | `DFEAFC` | `2B4163` | 导航、工具选择 |

应用色和对比关系由 `src/ui.rs` 定义，通过 Kit 注册两套主题。系统主题由已有外观机制解析。图像上的遮罩、对比色文字、选区线和 OCR 文字高亮单独定义：它们要对任意截图可读，用户选择的标注和贴图颜色不属于界面色表。

- 字体：系统无衬线。标题 22 / 28，正文 13 / 19，说明和提示 12 / 17，像素坐标可用系统等宽字体。表单说明可以换行，操作标签尽量单行。
- 间距：4、8、12、16、24，设置内容左右 24；交互控件之间可使用 4 像素，设置行上下 12。
- 圆角：紧凑提示 4、控件 6、浮动面板 10。描边 1 个逻辑像素；握把使用两色确保在明暗图像上可见。
- 阴影：贴图使用用户系统配置；浮动工具表面允许轻量阴影，普通设置表单靠表面和线条分层。
- 动效：操作状态即时更新（0 ms）；不添加进入动画、渐变或持续动画。原有拖尾和 GIF 动画是内容，不受控件样式管理。
- 密度：侧栏项约 32 高，设置控件优先 Kit Small，编辑工具保留短距离、单手操作的图标密度。在窄空间中允许工具行换行或滚动，不裁掉动作。
- 复用：设置行使用标题、说明和尾部控件；侧栏用 Kit Button 的焦点与选择反馈。截图、贴图编辑、任务控制共用浮层面板和信息标签；继续用 Kit 的输入、菜单、选择、开关、进度与无障碍标记。

组件的操作状态沿用 Kit 的 hover、pressed、selected、disabled 和键盘焦点。正文、辅助文字、主按钮和错误文字的配色在两主题下分别计算对比度，最低为浅色主按钮的 **5.94:1**；图片、半透明浮层和禁用状态未包含在此计算中。菜单栏与权限文件面板由操作系统绘制。手动模式会切换应用内主题；macOS 同步原生标题栏，Windows 标题栏跟随系统。

图标采用锁定版 GPUI Kit 的 Lucide 线性图标。表单与导航采用 Kit 原生控件；24 逻辑像素图标按钮用于主标注条，属性行保留紧凑控件。工具按钮保留文字标签供辅助技术使用，在提示中显示现有局部快捷键。画布本身不做入场动画，选区与笔触及时响应输入。
