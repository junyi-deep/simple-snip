# 已知问题与未完成事项

这是开发版本，尚不满足用户完整产品验收标准。以下不能用“编译成功”替代真实验收。

1. macOS 实际出现过 `_NSTouchBarFinderObservation` / `nextResponder` 的 AppKit KVO 崩溃，与上游 [GPUI Kit #3192](https://github.com/longbridge/gpui-kit/issues/3192) 相同。公开 Touch Bar provider 单独使用仍会复现。现已改为 macOS 窗口空壳池和单一工具浮窗隐藏复用，清空旧 Root 释放文档 / 任务，缩小空窗口降低资源占用。三轮句柄复用 / 文档释放探测和截图复制、贴图完成 / 取消 / 关闭短时回归通过；不宣称根治。早先激进原生探测有 4 条 `RefCell already borrowed`；已将原生移动调度到下一轮主线程队列，后续三轮探测不再出现。此修复不等同于 KVO 根因已根治。
2. 新版原位标注已在 macOS 实际回归矩形 / 箭头、撤销重做、复制到贴图、完成 / 取消、工具条下方 / 内侧定位。其余工具组合、小图、深色主题和双平台仍需验收。macOS 27 的约 30 逻辑像素底边白带已定位为 AppKit 对 titled 窗口的坐标约束；全屏 Overlay 改为实际 borderless 并重新定位，开发版桌面复测白带消失。多显示器 / Spaces 仍待验收。控件识别目前只有窗口级候选，AX / UI Automation 子控件层级识别未完成。
3. 跨显示器单一选区、显示器热插拔、混合 DPI、睡眠 / 远程桌面、设备丢失、Spaces / 全屏应用尚未完整验收。现有截图使用每显示器独立 Overlay。
4. 原生持续视频后端（ScreenCaptureKit / WGC / DXGI）未完成。当前 GIF 使用有界定时区域采集；实际 15/30 FPS 采集性能未测，不保证达标。系统鼠标指针捕获、鼠标特效包含开关、输出前 GIF 预览 / 二次参数调整尚未完成。现有结果可用系统应用预览。
5. 长截图只支持单向垂直稳定内容的几何重叠匹配；没有固定页头自动消除、横向拼接、虚拟列表 / 动画补偿。需选择不含固定页头的区域；重复 / 空白画面拒绝不可靠拼接或判断未变化。失败时保留已有结果。
6. OCR 为系统原生引擎，无离线 ONNX 模型回退。Windows 中英文组合效果需要语言包真机验证。取消在提交前 / 返回后检查，未实现所有后端正在执行时的立即中断。基础 TSV 按坐标间距估计，不支持合并单元格 / 多级表头，不是专业表格识别。
7. 剪贴板主要支持图片和文本形式的图片路径。GIF 动画贴图、普通文字贴图、颜色卡片、文件列表剪贴板格式、贴图位置跨重启恢复尚未完成；不实现贴图组。
8. 用户可调整核心设置，但开机启动、完整语言切换、命名规则编辑、日志文件轮换、全部设置项和历史策略 UI 仍未完整实现。历史索引的持久化已接入保存流程，列表当前仍按保存目录显示。
9. 原生小图工具浮窗、编辑后旋转 / OCR 坐标、热键冲突回滚与剪贴板失败反馈需要更多交互回归。文字输入已修复下一帧聚焦，并通过真实键盘与中文桌面输入回归；仍需 IME / 多行等组合测试。纯坐标和模型测试不能证明所有 UI 组合正确。
10. 鼠标拖尾已接入透明穿透窗口与有界轨迹；0.1.1 已显式清除 Kit Root 主题背景，加入贝塞尔平滑连接，去除重复采样端点光点；透明根节点 / 连续切线有自动测试。用户已实际确认透明桌面拖尾正常；多屏缩放映射、只刷新必要屏幕及功耗仍需验收。
11. Windows 原生 CI 的完整 GUI 编译、自动测试、Release 和 ZIP 已通过；签名与实际桌面交互验收未完成。macOS 包为 ad-hoc 本地测试包，未做 Developer ID 签名 / 公证，不能称正式发行版。
12. 第三方 `block 0.1.6` 触发 Rust future-incompatibility 提示，来自 GPUI 的依赖。当前 Rust 1.99 可编译；升级 GPUI 时需要统一依赖版本，不单独猜测替换。

下一步优先：完成新编辑交互的桌面验收与 KVO 回归；再补窗口控件识别、Windows 原生 CI / 真机检查、采集后端和产品化功能。不能把此清单中的未完成事项标记为 Phase 完成。

0.1.1 权限说明：旧逻辑会把 CG 预检 false 当作拒绝，现已增加 SCK 验证和原生提示；当前 `.app` 实际截图成功。临时 ad-hoc 包重建时 designated requirement 为 cdhash，本机无有效签名身份，不能保证授权跨构建保留。开关已开仍失败时需移除旧记录并添加当前应用；重启本身不能替换旧身份。未更改、重置或放宽 TCC。代码支持有效签名身份参数，但正式签名 / 公证仍未完成。

0.0.1 更新边界：更新支持检查、代理认证、下载、SHA256 校验和手动替换安装；没有后台定时检查、静默安装和代码签名身份验证。SHA256 用于检测损坏，不替代发行者代码签名。代理密码仅本次运行保留；系统代理采用底层库的 OS / 环境设置，不自行执行 PAC。功能仍可在完全离线状态使用，更新失败不影响截图。

0.0.2：设置窗口重开、工具条右侧空白、可配置贴图外框、编辑后选区缩放已实现并有自动 / 原生属性回归；2026-10-26 解锁后已补验截图、选区调整保留矩形、工具条右对齐 / 内侧避让和默认蓝边缩放。物理 F1 与菜单栏重开设置仍待人工确认。macOS 已更换公开 Carbon 热键分发后端；系统功能键仍可能需要 Fn/Globe 或替代组合，不强行覆盖系统保留键。Windows 编译与测试已有真实 CI，通过不等于 Windows 多显示器 / 用户交互验收。
