## 最新用户确认的交互

- 不使用独立图片编辑框。截图在冻结 Overlay 的选区内标注，贴图在原窗口内修改。
- 紧凑图标工具条贴近图像右下方；空间不足时放到图片下边框内侧上方。
- 贴图仅增加一个小型工具浮窗，解决小图无法容纳工具条的问题；不会把图像移走。
- 使用独立绘制的几何图标和 GPUI Kit 控件，不复制 Snipaste 专有素材。

- 权限：移除仅凭预检失败的拒绝逻辑，新增 SCK 当前身份验证、具体服务错误、原生消息框和系统设置跳转；本机当前包截图成功，临时签名持续性限制单列记录。
- 图标：蓝底白色裁切标记，收紧两个边框；SVG / PNG / ICO / ICNS / 托盘共用原创图形。

用户实测确认拖尾透明正常，反馈采样点明显和淡出过慢。已移除每段首尾叠加的圆形光点；默认生命周期从 500ms 缩短为 300ms，临时观察用的 3000ms 本机设置也恢复为 300ms，其余设置保留。
