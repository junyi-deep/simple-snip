# Simple Snip v0.0.27

- Windows 悬浮标注工具栏和 OCR 结果面板去除系统外框，窗口高度按实际内容计算。拖动 OCR 面板缩放时，内容和窗口边缘同步调整。
- 输入水印文字后按回车即可放置或更新水印，点击图片仍可指定位置。新截图会清空文字，保留上次通过滑块设置的角度。
- GIF 默认录入系统鼠标指针，可在偏好设置的「GIF 录制」页关闭。

macOS 下载包使用临时签名，尚未完成 Apple 公证。更新后如需重新授权录屏，请在系统设置中选择当前安装的 Simple Snip。详见 [安装与录屏授权](https://github.com/junyi-deep/simple-snip/blob/v0.0.27/docs/BUILD.md)。
