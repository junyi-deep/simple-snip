# Simple Snip v0.0.8

- 编辑工具栏按实际按钮内容计算宽度，去除固定 840px 产生的空白；形状、尺寸选项按需决定宽度，窄屏继续保持单行横向滚动。
- Esc 从画布、文字输入框、数值输入框和独立工具栏都可取消整次编辑；贴图保留进入编辑前的内容，不误关贴图。截图编辑按 Esc 取消本次截图。
- 记住上次选择的工具、形状、线条样式、颜色、各工具独立的字号 / 粗细、箭头样式与下一个标号。保存于用户配置目录的 editor.toml，下次进入编辑及应用重启后恢复。后台串行写入，合并待保存设置，不阻塞鼠标交互；损坏文件回退默认值。

验证包含工具栏实测布局、Esc 焦点 / 取消链路、跨编辑器独立参数恢复，以及配置序列化、非法值和损坏文件恢复。Windows 本地常规测试 67 项通过；完整物理鼠标、多屏和双平台目视验收仍需补充。
