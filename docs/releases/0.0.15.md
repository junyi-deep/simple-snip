# Simple Snip v0.0.15

修复 [issue #2](https://github.com/junyi-deep/simple-snip/issues/2)：

- 截图选区点击「复制图片」或按 Ctrl/Cmd+C，图片成功写入剪贴板后自动结束截图；写入失败保留选区并提示重试。从已有贴图复制图片不会关闭贴图，OCR 选中文字复制仍保留当前界面。
- F3 支持把剪贴板中的图片、纯文本、RTF 富文本、HTML 富文本及表格直接转换成独立贴图，复用拖动、缩放、透明度、标注和另存为功能。优先使用图片及原生 RTF，HTML 保留常见字体、字号、加粗、斜体、下划线、颜色、底色、对齐、表格边框、列宽及合并单元格；制表符文本按表格排列。
- 富文本在后台用系统文字引擎绘制，无需打开浏览器或授予屏幕录制权限。仅绘制本地文字与表格，不执行脚本、激活嵌入对象或加载远程图片；过长内容提示分段复制。
- 先测量排版高度再分配位图，裁剪外围空白；连续按键合并正在处理的剪贴板任务，避免重复转换堆积。Windows 绘制窗口、位图、DC 和排版缓存及时释放，系统 RichEdit DLL 在进程内保留一次加载。

验证覆盖复制成功 / 失败和贴图保留、中文 / emoji、HTML 片段字节偏移及继承样式、表格颜色 / 列宽 / 合并单元格、RTF 对象过滤和重复绘制资源回收。发布前双平台预检通过：Windows 104 项、macOS 99 项 Rust 测试；本机额外 3 项原生截图/OCR 测试及最终 Release smoke 通过。完整记录在 docs/TESTING.md。
