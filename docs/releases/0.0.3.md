# Simple Snip v0.0.3

本版先发布供试用，桌面交互验证后续补做。新图标的菜单栏外观、长截图 / GIF 控制栏的实际采集与排除、设置页最小尺寸下的显示仍待验收；不将自动测试与构建成功视为这些项目已通过。

- 贴图默认未选中无边框，点击选中显示可配置蓝边；局部 Esc、Command+W / Ctrl+W 和右键关闭统一释放资源。用户已确认 macOS 选中与关闭正常。
- 应用图标使用参考提供的 SimpleTodo 样式：#2563EB 蓝底、白色圆角裁切标记。macOS 菜单栏使用独立透明底模板图标，随系统适配深浅外观；Windows 保持彩色应用图标以适应任务栏背景。
- 长截图与 GIF 改用选区右下方的无标题控制栏；空间不足时放到选区内侧。录制期间控制栏保持可用，提供开始、暂停 / 继续、停止保存、取消和结果预览。
- 长截图选择区域后自动监测手动滚动，匹配左 / 右 / 上 / 下方向，反向回滚不重复追加；也可自动向下滚动。匹配失败保留内容，支持暂停、继续与完成编辑。采集上限 5 分钟 / 600 段，内存预算 256 MiB。
- macOS 使用 ScreenCaptureKit 截图过滤器排除控制栏；Windows 使用公开 WDA_EXCLUDEFROMCAPTURE。本版 Windows 目标要求 Windows 10 2004 或更新版本 / Windows 11。
- 设置说明允许换行，侧栏与内容可滚动，修复最小窗口下的文字截断约束。

本机及双平台预检均通过：macOS 47 项自动测试、Windows 45 项自动测试，另各有 3 项原生桌面测试默认 ignored。预检包含 fmt、check、Clippy、Release 和打包：[双平台预检流水线](https://github.com/junyi-deep/simple-snip/actions/runs/40429397908)。后续桌面验收记录见 docs/TESTING.md。

限制：适用于稳定内容的逐次水平 / 垂直滚动，不保证对角滚动、固定页头、虚拟列表、动画或重复纹理的拼接。换轴后未访问区域保留透明。GIF 当前仍为有界逐帧采集，未宣称 15 / 30 FPS 性能达标。

**未签名开发测试包**：macOS ad-hoc，未完成 Developer ID 签名 / 公证。系统录屏授权可能需要对当前应用重新确认。更新下载校验后手动替换。Windows 首次运行需要 [微软官方 x64 Visual C++ v14 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。
