# Simple Snip v0.0.6

- 优化重复截图：复用每个显示器的空截图窗口和渲染器，关闭时释放旧截图及编辑实体；大图 RGBA/BGRA 转换使用有界并行任务，并增加分段耗时日志。
- 修复贴图连续点击被识别成双击后隐藏；点击和拖动不再隐式隐藏贴图，关闭仍用 Esc / Ctrl+W / 右键菜单。
- 文字标注改为透明原位输入，只显示文字和选择边框，移除背景输入框、占位提示和确认按钮。回车完成，Esc 取消；保留输入法及键盘编辑。
- 标号工具显示下一序号，工具栏提供加减调整，落点后自动递增。
- 设置窗口使用普通应用窗口样式，支持 Windows 任务栏 / Alt+Tab；创建、重开和激活时均不再始终置顶。
- 长截图 / GIF 的活动采集区域保留透明穿透边框；选区确认工具栏和采集控制栏均靠区域右下角，屏幕边缘时向内避让。边框绘制在采集范围外，Windows 额外从采集中排除。
- 包含此前工作区的 Windows 拖尾层级、截图期间显示、原生贴图拖动、首次显示定位及多余原生边框修复。

验证包括原生坐标 / 无边框窗口 / 普通应用窗口属性、GPUI 键盘文字输入及标号序列、截图窗口复用与文档释放。Windows 原生 smoke 通过实际截图和窗口生命周期检查。Debug 分段测量中首次窗口根节点创建约 282ms，复用约 0–1ms；这些数据不是 Release 性能基准或完整目视验收。混合 DPI 多屏、物理鼠标拖动和任务栏动态覆盖仍需更多实机复查。
