首个公开开发版本，仅面向 Windows AMD64 和 macOS ARM64。

- F1 区域截图，F3 剪贴板贴图；多个独立贴图窗口。
- 截图 / 贴图原位标注、右下工具栏、编号、三种箭头、对象选择与滚轮粗细、原位文字输入。
- 本地系统 OCR、基础长截图和 GIF 录制；已知限制见仓库文档。
- 全屏透明彩虹鼠标拖尾，连续颜色 / 宽度插值，可调淡出时间，默认 300ms。
- GitHub 版本检查、按平台下载与 SHA256 校验；支持系统代理、直连、自定义 HTTP 代理及可选认证。

制品为未签名的开发测试包，macOS 使用 ad-hoc 本地签名，未完成 Developer ID 公证。系统权限请由用户授权；测试包替换后可能需要重新添加录屏权限。下载校验后手动退出并替换安装。不要覆盖用户配置目录。

CI 构建通过仅表示格式、编译、静态检查和自动测试通过，不等同于 Windows/macOS 的全部真实桌面验收。多显示器、混合 DPI、长期窗口生命周期及完整产品化工作仍在推进，详见 docs/KNOWN_ISSUES.md。
