# Simple Snip 0.0.21

修复 [issue #6](https://github.com/junyi-deep/simple-snip/issues/6) 中的截图和标注体验问题。

- 按 F1 进入截图后，无需点击或框选即可按 Esc 取消。
- 多屏时，框选前将鼠标移到另一块屏幕，截图界面会跟随。开始框选后，选区保持在当前屏。
- 使用文本标注工具点击图片时，输入框左侧的光标与点击位置垂直居中对齐。

提供 Windows AMD64 和 macOS ARM64 安装包。macOS 最低 15.0，本次仍发布未公证测试包。Windows 需要微软 x64 Visual C++ v14 运行库。
