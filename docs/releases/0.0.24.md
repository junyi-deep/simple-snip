# Simple Snip v0.0.24

完成 [issue #7](https://github.com/junyi-deep/simple-snip/issues/7) 的标注、OCR 和桌面交互优化。

- 新截图的标号从 1 开始，已有贴图进入标注时默认使用选择工具。选中线条、箭头和图形时保留调整手柄，移除蓝色矩形框。
- 图片水印可设置字号、颜色、粗细及单个、疏、中、密四个密度档位。高斯模糊和马赛克共用工具入口，默认使用高斯模糊。
- OCR 在 Windows 使用离线 RapidOCR，在 macOS 使用 Apple Vision。偏好设置按平台显示各引擎的参数，提供快速、均衡、精确三种预设，支持修改、还原和复制为自定义模式。可从标注工具栏切换模式。
- OCR 结果框默认与标注工具栏等宽，支持拖动调整宽高和 Ctrl/Cmd+C 复制选中文字。OCR 结果打开时，切换应用会保留当前贴图的标注工具栏。
- 双击托盘或菜单栏图标打开偏好设置，右键打开菜单。F3 从剪贴板直接贴出图片时，图片按原始像素尺寸显示。

Windows 版内置识别模型，OCR 无需下载模型或安装 Python。macOS 测试包为 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。
