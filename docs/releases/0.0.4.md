# Simple Snip v0.0.4

- 修复截图「贴到桌面」时自动居中、改变显示尺寸的问题。现在保留当前选区的桌面位置和逻辑尺寸，支持 Retina 比例及调整选区后固定；透明边框 / 阴影留白位于图片外侧。剪贴板 / 历史图片继续自动适配。
- 彩虹鼠标拖尾默认开启，可以从托盘或偏好设置关闭；用户已经保存的关闭选择会保留。
- 补充 macOS 桌面验收：长截图垂直 / 水平拼接、反向回滚去重、暂停 / 继续、完成标注与 PNG 导出；GIF 开始 / 暂停 / 继续 / 取消 / 保存与系统预览；全屏录制时排除区域内控制栏；760×540 最小设置窗口文字与控件显示。

本机及[标签发布流水线](https://github.com/junyi-deep/simple-snip/actions/runs/40528736685) 全部通过：macOS 49 项、Windows 47 项自动测试，各有 3 项系统桌面测试默认 ignored。两个原生目标均完成 fmt、check、Clippy、Release、打包和自动发布。三个公开安装包已下载验证 SHA256、ZIP 完整性、目标架构 / macOS 版本及 DMG 校验。具体执行记录见仓库 docs/TESTING.md。

已知限制：自动滚动需要 macOS 辅助功能权限，本机已验证权限不足提示及保留已有内容，授权后的自动滚动成功路径尚未验收。Windows 桌面、多显示器、Spaces 和最低系统真机矩阵仍待验证；GIF 为有界逐帧采集，没有 15 / 30 FPS 达标结论。长图换轴后未访问区域保留透明，复杂动态 / 固定页头场景仍受限。

**未签名开发测试包**：macOS 采用 ad-hoc 签名，未完成 Developer ID 签名 / 公证；换包后系统可能要求重新确认当前应用的录屏权限。Windows 首次运行需要 [微软官方 x64 Visual C++ v14 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。仅提供 Windows AMD64 和 macOS ARM64 包，更新下载验证后手动替换。
