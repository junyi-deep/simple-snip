# Simple Snip v0.0.16

- 自动更新改为在设置窗口内持续显示同一个进度条及下载百分比，检查、下载、校验和安装状态不再反复弹出消息通知。
- 更新进行中切换设置页面仍能看到进度；失败时显示原因并恢复重试按钮。
- 下载进度最多每 100ms 推送一次，减少快速下载时的界面刷新开销；校验及安装阶段切换保留可靠传递。

新增回归测试连续渲染 0%～100% 的进度，确认通知列表始终为空，并覆盖校验、安装、失败和重试状态。发布前本机 51 项应用测试、格式检查及 Clippy 检查通过。
