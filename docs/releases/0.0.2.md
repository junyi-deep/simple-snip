## 修复

- 有置顶贴图时重新显示、激活偏好设置；设置失焦后恢复普通层级。
- macOS 改用公开 Carbon dispatcher 热键后端和独占注册，补充冲突错误与触发日志；默认全局绑定仍仅 F1 / F3，不绕过系统功能键。
- 编辑工具条按实际控件收紧并右对齐，排除贴图阴影边距。

## 新增

- 默认细蓝色贴图边框，可设置 #RRGGBB 颜色、0–8px 粗细和阴影开关，保存立即生效；复制 / 导出不包含外框。
- 截图标注时支持拖动八个选区手柄调整宽高，Shift+方向键按像素微调；已有标注及撤销 / 重做坐标保留。
- 延续连续渐变拖尾、可调淡出时间、GitHub 更新检查、HTTP 代理认证与校验下载。

macOS 本机 40 项自动测试及原生窗口属性 / 生命周期探测通过。发布制品由 Windows AMD64 / macOS ARM64 CI 构建；CI 成功不代表全部真实桌面、多屏或物理功能键验收通过。最终 F1 / Fn、工具条和边框目视回归因测试桌面锁屏待人工确认。
