# Simple Snip 0.0.22

- 按 F1 进入截图时，所有屏幕在框选前就会变灰。开始框选前可直接换屏；开始框选后锁定当前屏幕，Esc 关闭全部遮罩。
- 重设计偏好设置的 11 个页面，提供浅色、深色和跟随系统三种外观。长页面可滚动，PNG / JPEG 默认格式会自动保存。
- 统一原位标注、OCR、贴图提示及长截图 / GIF 控制栏的外观。标注工具仍贴在选区右下角，空间不足时移到选区内侧。
- 应用菜单显示当前配置的截图和贴图快捷键。默认全局绑定仍是 F1 和 F3。

提供 Windows AMD64 便携 ZIP，以及 macOS ARM64 ZIP 和 DMG。macOS 最低 15.0，本次为未公证测试包。Windows 需要 Microsoft Visual C++ v14 x64 运行库。
