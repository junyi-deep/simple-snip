# Simple Snip v0.0.18

- F3 按标注工具栏状态处理：工具栏打开时贴出当前修改的图片；截图生成独立贴图，已有贴图则提交修改、关闭工具栏并聚焦当前贴图。其它情况读取系统剪贴板中的图片、文本、富文本及表格。
- 重复内容不再创建新贴图，自动显示、聚焦并用蓝色边框高亮已有贴图 1 秒；重复触发会重新计时。隐藏或鼠标穿透的贴图也可恢复交互，关闭常规边框时仍能看到高亮。
- 按完整分辨率 RGBA 像素判重，显示缩放、透明度、边框和阴影不影响判断；已修改的图片按当前合成内容比较，动态 GIF 不与静态首帧混淆。
- 修复富文本格式读取失败导致纯文本回退被跳过的问题，Windows 剪贴板短暂被占用时在后台有限重试。

本机 111 项测试、fmt / Clippy 及 Release 原生窗口冒烟检查通过。回归覆盖标注修改实际进入导出像素、工具栏关闭后的剪贴板读取、重复内容聚焦、高亮计时重置及像素不同仍创建新贴图。
