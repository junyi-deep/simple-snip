# Simple Snip v0.0.25

- OCR 结果可以原位编辑。新增 Go 和 Java 高亮，支持按所选语言离线格式化，可撤销。编辑器默认自动换行、隐藏行号，选中文本以蓝色标记，识别模式会记住上次的选择。
- macOS 的 Vision 识别改在独立进程运行。精确模式 6 秒未返回时，会转为快速识别并提示。扫描中可取消并立即重试，贴图会忽略已取消任务的结果。
- 水印文字可在标注工具栏的字号控件后输入，点击图片放置，选中已有水印后可修改文字并按回车应用。
- 彩虹拖尾从光标端的蓝色连续过渡至尾端的粉红色。
- 单击菜单栏或系统托盘图标打开偏好设置，右键打开功能菜单。macOS 设置窗口恢复原生阴影。
- macOS 录屏提示显示正在运行的 `.app` 路径，便于在系统设置中为当前安装包授权。

macOS 下载包使用临时签名，尚未完成 Apple 公证。更新后如需重新授权录屏，请在系统设置中选择当前安装的 Simple Snip。详见 [安装与录屏授权](https://github.com/junyi-deep/simple-snip/blob/v0.0.25/docs/BUILD.md)。
