# Simple Snip v0.0.13

- 鼠标拖尾新增彗星、光点和涟漪，保留柔光丝带；支持彩虹、单色及双色渐变，ColorPicker 可调整颜色与透明度。设置提供实际绘制器预览，保存后立即应用并持久化。
- 限制丝带采样点、光点和涟漪数量，避免快速移动时产生无界绘制工作；光点与涟漪不再计算未使用的丝带几何。
- 快捷键注册失败及恢复不再弹出通知；只在设置的「快捷键」页面显示当前状态，失败项仍每 5 秒自动重试，成功项保持注册。
- README 仅保留核心优势和六项主要功能，各配真实应用界面截图。截图使用本地示例内容，不包含私人桌面资料。

Windows 本机 92 项常规测试、3 项原生截图 / OCR 测试和最终 Release 原生窗口 smoke 通过，fmt / Clippy 通过。双平台构建和测试由标签工作流执行；桌面原生检查及完整验证记录见 docs/TESTING.md。
