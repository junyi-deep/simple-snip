# Simple Snip v0.0.5

- 修复 Windows 显示缩放下鼠标拖尾偏离指针的问题：以真实窗口客户区转换物理屏幕坐标，再应用窗口 DPI；支持负坐标原点。
- 修复截图结束后拖尾恢复和贴图遮挡拖尾的问题。截图暂停时清空轨迹，Windows 保持透明窗口映射；截图退出、新建或激活贴图后恢复拖尾的置顶层级。
- 去掉 Windows 贴图右上角多余的系统关闭按钮。仍可用 Esc、Ctrl+W 或右键菜单关闭贴图，滚轮缩放保持可用。
- 优化截图、贴图响应：图像颜色转换移到后台线程；Windows 窗口吸附只枚举必要的矩形信息；关闭拖尾时省去截图前等待，Windows 开启拖尾时减少等待；恢复移动时按设定帧率采样。

本机 Windows AMD64 的 49 项自动测试通过，3 项系统测试仍默认 ignored。原生窗口探测通过三轮实际截图 / 取消 / 拖尾恢复，以及贴图创建、系统按钮标志、透明度、穿透恢复、窗口和文档释放检查。DPI 回归使用隐藏原生窗口验证 100% / 125% / 150% / 200% 坐标转换，不等同于已完成真实混合 DPI 多屏验收。尚无 Release 性能基准或物理鼠标动态效果的完整验收结论。跨平台发布制品由标签流水线构建。

**未签名开发测试包**：仅提供 Windows AMD64 和 macOS ARM64。Windows 首次运行需要[微软官方 x64 Visual C++ v14 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。macOS 为 ad-hoc 签名，未完成 Developer ID 签名 / 公证；本次未在本机执行 macOS 桌面回归。
