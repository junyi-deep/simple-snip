# Simple Snip v0.0.17

- 修复 Windows 鼠标拖尾被排除在会议录屏及屏幕共享之外的问题，默认允许拖尾进入整屏捕获。
- 设置 → 鼠标拖尾新增「在录屏和屏幕共享中显示」，支持自动保存；关闭后恢复原有排除行为。旧配置自动使用开启状态。
- 本工具截图采样、长截图和 GIF 采集期间临时排除拖尾，采集结束后恢复用户设置；截图采样完成即恢复，无须等选区或标注结束。本地拖尾在原生排除成功时持续可见。
- 清除复用窗口残留的捕获排除标记，避免开关重新开启后仍无法共享拖尾。

本机 108 项测试、fmt / Clippy 和 Release 原生窗口冒烟检查通过。独立拖尾窗口需要整屏捕获；单应用共享、游戏捕获等模式仍可能不包含拖尾，会议软件远端画面尚未实测。
