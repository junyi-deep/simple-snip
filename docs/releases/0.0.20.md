# Simple Snip 0.0.20

修复 [issue #5](https://github.com/junyi-deep/simple-snip/issues/5)。

- 按 2 切换矩形，按 3 切换椭圆，来回切换时两项各自保留颜色和线宽。
- 图形绘制完成后自动选中。拖动边缘或角上的控制点调整宽高，直线和箭头可以拖动端点。使用选择工具重新选中已有图形也能调整。
- 滚动鼠标滚轮立即调整选中的图形线宽。拖动尺寸和调整线宽均可撤销。
- Windows OCR 使用独立进程。系统识别意外退出或超时时，当前任务会提示错误，编辑器可继续使用。

提供 Windows AMD64 和 macOS ARM64 安装包。macOS 最低 15.0，本次仍发布未公证测试包。Windows 需要微软 x64 Visual C++ v14 运行库。
