# Simple Snip 0.0.23

- 偏好设置更紧凑：导航分组、图标和可视化主题预览替代长说明，状态消息使用悬浮提示。
- 默认启动时检查更新，开启后每小时在后台静默检查。可在「软件更新」停用；发现新版本时，点击设置窗口右上角通知可打开更新页。安装仍由用户确认。
- OCR 识别时显示扫描反馈；结果框位于工具栏下方，默认展示四行，支持横向和纵向滚动，以及拖拽调整大小。使用结果框右上角的复制按钮，也可复制表格 TSV；再次点击 OCR 会重新识别。
- 箭头样式改用实际图形预览。标注按钮恢复小号快捷键提示；按 W 或点击印章图标可在图片上添加可编辑、可撤销的半透明文字水印。

提供 Windows AMD64 ZIP 和 macOS ARM64 ZIP / DMG。macOS 最低 15.0，本次仍为未公证测试包。Windows 需要 Microsoft Visual C++ v14 x64 运行库。
