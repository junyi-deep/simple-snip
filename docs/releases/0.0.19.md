# Simple Snip 0.0.19

修复 [issue #4](https://github.com/junyi-deep/simple-snip/issues/4) 的截图行为：

- 多显示器下，每次只在按 F1 时鼠标所在显示器创建一个截图窗口，避免多个屏幕各自保留独立截图和编辑器。
- 进入截图后立即高亮鼠标下的窗口，无需先移动鼠标；支持负坐标和 Retina / 混合 DPI 映射，窗口越界时裁剪到当前屏幕。
- 鼠标下没有窗口时保持未框选。空白处单击、回车或方向键不再隐式选择整屏；仍可拖动框选，或按 A 明确选择当前整屏。
- 重复的截图结果不会创建额外窗口，取消后可正常重新截图。

本次仅发布 Windows AMD64 与 macOS ARM64；macOS 最低 15.0。安装包仍为未签名 / ad-hoc 测试包，未执行 Developer ID / Apple 公证。Windows 需要微软 x64 Visual C++ v14 运行库。真实双屏和 Windows 桌面完整验收仍需独立设备验证。

[双平台构建与测试](https://github.com/junyi-deep/simple-snip/actions/runs/42833821368) 已通过：Windows 118 项、macOS 112 项常规测试，各跳过 3 项原生权限测试。公开下载的三个安装包已核验 SHA256、ZIP / DMG 完整性、架构和 macOS 版本。macOS 原生合成画面验证空选区回车、A 全选、标注与取消通过；窗口生命周期探测输出 SMOKE PASS，但另观察到 GPUI 重入告警，详见 [测试记录](https://github.com/junyi-deep/simple-snip/blob/main/docs/TESTING.md)。
