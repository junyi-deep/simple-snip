# Simple Snip 0.0.14

偏好设置修改后自动保存，不再需要点击保存按钮。

- 文本输入停止约 500ms 后保存；开关、帧率、主题和动画选项立即保存并应用。
- 关闭设置窗口或退出应用时提交尚未完成的输入。无效数值或配置写入失败时显示原因，保留原配置，修正后可继续保存。
- 修改设置时仅合并实际改动的字段，避免覆盖托盘拖尾开关或保存图片时选定的新目录；无关设置不再重启拖尾或刷新贴图边框。
- macOS 发布脚本和标签流水线支持 Developer ID Application 签名、Apple 公证、应用和 DMG 票据附加及 Gatekeeper 校验。所有步骤成功后才输出正式包；更新器在两类包同时存在时优先选择正式命名的包。

## 安装与限制

仅提供 Windows AMD64 和 macOS Apple Silicon ARM64。macOS 最低 15.0。

**本次按维护者要求发布未公证测试包。** 尚无 Apple Developer ID 证书和公证凭据，macOS 文件仍带 `_unsigned`，下载后可能继续出现“Apple 无法验证”提示。这与录屏权限不同，重设录屏权限不能消除该提示；正式修复需配置证书并发布通过公证的新包，见 [签名与公证配置](https://github.com/junyi-deep/simple-snip/blob/main/docs/MACOS_SIGNING.md)。Windows 包也未签名。

截图、OCR 和剪贴板始终在本地处理；默认全局快捷键仍只有 F1 截图、F3 贴图。Windows 需安装微软官方 x64 Visual C++ v14 运行库。

## 验证

[双平台流水线](https://github.com/junyi-deep/simple-snip/actions/runs/41320304485) 全部通过：Windows 97 项、macOS 93 项测试，各跳过 3 项原生权限测试；macOS 额外 6 项公证流程模拟测试通过。公开下载的三个安装包均已核验 SHA256、完整性、目标架构及 macOS 版本。签名与公证模拟测试不代表真实 Apple 公证通过。
