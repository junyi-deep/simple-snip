# Simple Snip v0.0.28

- macOS 应用内升级会检查新旧签名是否兼容。签名不兼容时，更新器会在替换应用后尝试清除旧录屏授权，再启动新版。
- 新版显示清理结果，并提供系统设置入口。录屏权限由用户重新确认。自动清理失败时，仍可在系统设置中移除旧条目并添加当前应用。
- 从 v0.0.27 或更早版本升级到本版仍使用旧更新器。安装本版后，下一次应用内升级才会执行自动清理。

macOS 下载包使用临时签名，未经 Apple 公证。详见 [安装与录屏授权](https://github.com/junyi-deep/simple-snip/blob/v0.0.28/docs/BUILD.md)。
