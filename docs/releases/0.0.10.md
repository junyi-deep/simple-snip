# Simple Snip v0.0.10

- 修复 Windows Debug 截图进入编辑时崩溃：实际系统转储的故障点为 `_alloca_probe`，栈接近默认 1MB 上限，返回地址定位至编辑工具栏 DropdownMenu 构建。拆分三个下拉构建函数并擦除中间控件类型，开发配置优化应用构建函数，Windows 程序保留 8MB 栈空间（不预先提交全部内存）。
- 快捷键增量注册：保留成功项，失败项每 5 秒重试，支持服务初始化失败后重建；退出时停止重试。提示包含具体组合键，打开设置可重新查看当前错误。无法通过支持的系统接口可靠查询占用应用名称，因此不猜测占用方。
- 设置保存先验证格式与内部冲突，允许保存暂时被其他应用占用的有效组合键；稍后释放时自动注册。保存失败、更新状态、快捷键冲突和恢复均使用 Notification，移除底部状态提示。更新进度复用同一通知。
- 设置边框颜色使用 ColorPicker 替换手动颜色值输入，编辑器颜色也改为 ColorPicker，支持任意颜色并保存。
- 性能：渲染 / OCR 不再复制撤销重做历史；RGBA/BGRA 转换移至后台；合并刷新请求，减少无变化时的布局更新。连续画笔 / 曲线增加采样间距和 8192 点上限。
- 后续 Rust panic 会将回溯保存在用户配置目录 panic.log；原生异常仍需系统崩溃转储。保留此前本地构建修复：项目固定 Rust 1.99.0。

验证包括 75 项 Windows 常规测试：真实 RegisterHotKey 占用 / 释放 / 重试恢复、未冲突项保持注册、Notification 保存错误、ColorPicker 更新及持久化、无历史渲染快照等。fmt / Clippy 通过。新版原生 smoke 自动进入截图编辑并显示箭头工具栏和 ColorPicker，连续截图 / 取消及窗口复用通过，输出 SMOKE PASS；PE 栈保留值实测为 8388608 字节。完整跨应用 / 多屏和所有弹层目视回归仍需继续补充。
