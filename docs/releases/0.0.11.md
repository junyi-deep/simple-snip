# Simple Snip v0.0.11

- 修复标注 ColorPicker 弹层被滚动容器和贴图工具栏原生窗口截断；打开弹层时扩展透明窗口空间，工具栏本身保持原位。
- 箭头样式与颜色、线宽位于同一选项行，移除多余的独立行。图片提示的开关和消失时间移到设置窗口「基本」，不再占据标注工具栏。
- 原位文字输入增加黑白高对比度插入光标，避免焦点返回画布时抢走文字输入焦点；文字提交后保留即时预览，直到后台渲染结果就绪，避免消失后重现。
- OCR 选中文字后，Ctrl/Cmd+C 直接复制选区；即使工具栏文字修正输入框有焦点，也不会误复制输入框内容。
- 编辑已有贴图时，F3 和工具栏「贴图」均完成当前编辑、关闭工具栏并保留当前贴图，不再创建副本。普通 F3 剪贴板贴图行为保留。
- 长截图 / GIF 控制栏创建后取得键盘焦点；数字快捷键恢复，编辑帧率 / 间隔时不会误触动作，Enter 返回控制栏，Esc 取消。标注工具栏聚焦时也支持工具快捷键和 L / G 模式切换。
- GIF 停止仅完成编码并保留会话临时文件；停止后提供独立「预览 [4]」和「保存 [5]」。预览在原选择区域播放，可再次点击关闭；保存打开系统另存为对话框，取消保存仍保留临时结果。关闭控制栏或重新录制时清理未保存结果。
- GIF 预览后台逐帧解码，通过有界队列播放并保留帧间隔，避免一次性解码整段动画；关闭预览停止解码。保存使用目标目录临时文件后原子替换，不将整段 GIF 读入内存。

Windows 本机 81 项常规测试通过，覆盖弹层空间、箭头单行选项、提交文字预览、OCR 输入框焦点下的 Ctrl+C、F3 当前贴图路由、GIF 数字控制、帧播放时序和显式文件保存。完整物理键盘、多屏 / 缩放、IME 输入与所有颜色面板的目视回归仍需持续补充。
