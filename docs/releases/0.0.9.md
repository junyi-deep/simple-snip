# Simple Snip v0.0.9

- 工具栏左对齐内容，按实际按钮宽度收紧；取消 OCR 模式的固定宽度，箭头样式改为下拉选择，避免样式按钮撑出大片空白。
- 截图编辑中 F3 优先将当前选区及标注固定为贴图，保持位置和尺寸；未截图时继续从剪贴板贴图。
- OCR 保留原图及原文字显示，移除白底文字覆盖层，I 形光标直接在识别位置拖选；支持 Ctrl/Cmd+C 和全选，保留原图坐标选择高亮。
- 识别、合成和复制消息改为图片上边框内侧的小字 toast，不占工具栏空间；默认 2 秒消失，「提示」菜单可关闭或设置 1/2/3/5 秒。复制图片后保留编辑画面，以显示反馈并支持继续 F3 贴图。
- 默认燕尾箭头，新增实心 / 空心三角形、圆点和菱形头；预览、导出和命中边界共用路径，空心内部保留原图。保留三种旧箭头供选择。
- 修复选中已有标注后切换工具会覆盖默认粗细；字号 / 线宽输入仅在数值变化时保存，避免焦点事件回写旧值。箭头粗细和样式、各工具参数、提示开关和延迟持久化。旧版默认普通箭头迁移为燕尾，保留其他已选箭头样式。

验证：本机 71 项常规测试覆盖工具栏内容宽度、F3 当前编辑器路由、原图 OCR 状态、toast 到期 / 禁用 / 工具栏高度不变、七种箭头导出及空心保留背景、工具切换和偏好文件恢复。fmt / Clippy 通过。物理键盘全局 F3、多屏、复杂 OCR 字符边界和完整桌面目视验收仍需更多实机复查。
