# Simple Snip v0.0.7

根据 [Issue #1](https://github.com/junyi-deep/simple-snip/issues/1) 改进截图、贴图、编辑及更新流程。

- Windows 贴图拖动改用物理坐标增量更新，避开阻塞界面和拖尾刷新的原生模态拖动循环。选中贴图后，鼠标移出图片仍可滚轮缩放，Ctrl+滚轮调整透明度；进入编辑、穿透或失焦后释放全局滚轮。滚轮按事件分发，无持续轮询。
- 编辑工具栏主操作保持单行，显示绘图快捷键；窄屏可横向滚动。字号、线宽支持数值输入、加减与滚轮，字体调整按像素生效。输入文字的光标行高随字号和图片显示比例变化。
- 矩形工具增加圆角、椭圆、菱形、三角形；线条增加折线、平滑曲线。折线点击添加节点，双击 / Enter 完成。预览和导出使用相同路径。
- 马赛克显示工具图标和作用范围，按下即涂抹，拖动期间持续更新；整笔可一次撤销。合成任务合并后续请求，避免每个移动事件都排队处理整张图片。
- OCR 结果使用文字选择区域和 I 形光标，支持字符 / 跨行选择、Ctrl/Cmd+C、全选、全部复制和 TSV。结果只读，保留选中行修正；修复 Windows 引擎在相邻汉字间插入的多余单个空格。
- 保存图片打开系统另存为对话框，记住上次选定目录；支持 PNG / JPEG。
- F1 框选后，工具栏首个「截图 ▾」可切换长截图 / GIF；画布快捷键 L / G。活动区域显示边框，右下控制栏随模式切换。长截图间隔和 GIF FPS 可输入、加减；采集操作显示数字快捷键。
- 更新改为「升级并重启」：下载及 SHA256 校验完成后准备安装文件，安装助手等待当前应用退出，再替换并重启；替换 / 启动失败时尝试恢复旧版本。安装目录需可写，macOS 需从 .app 运行。保留旧版本备份和安装日志。

**升级说明**：0.0.6 及更早版本的更新入口只会下载，请先手动安装 0.0.7。一键升级流程从 0.0.7 起可用。

**验证范围**：Windows workspace 62 项自动测试通过，fmt / check / Clippy（-D warnings）通过。原生 smoke 完成三轮截图 / 取消 / 拖尾显示、贴图生命周期、普通设置窗口样式和窗口复用检查。Debug 本机首轮 Overlay 根节点创建约 259ms，复用约 0–1ms；这是包含实际采集的开发探测，非 Release 性能基准。额外显式运行的 3 项原生测试（连续截图、奇数像素区域、中英文 OCR）也全部通过。归档准备测试包含单引号路径、重复可执行文件拒绝和原程序不变断言。

Windows 界面自动化因无法确认浏览器 URL 停止；自动审批阻止了执行临时安装替换 / 回滚测试，完整自动安装重启尚未端到端实测。物理拖动、多屏混合 DPI、全局滚轮及完整工具组合仍需更多目视回归。Issue 最后的「分析」未列具体功能，按性能分析与上述记录处理。

**未签名开发测试包**：Windows AMD64 需要微软 x64 Visual C++ v14 运行库；macOS ARM64 使用 ad-hoc 签名，未完成 Developer ID / 公证，更新后可能需要重新授权录屏。SHA256 用于校验文件完整性，不替代发行者签名。
