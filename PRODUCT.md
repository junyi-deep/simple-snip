# Simple Snip
<!-- impeccable:product-schema 1 -->

## Platform
Windows AMD64 / macOS ARM64 native desktop, GPUI Kit.

## Stack
Rust Stable workspace; GPUI Kit as the only application GUI; native OS backends.

## Product Purpose
A resident, offline screenshot and independent image pin tool, with non-destructive annotation, local selectable OCR, scrolling capture, GIF recording and optional global rainbow cursor trails.

## Capabilities and Constraints
User's brief is authoritative. Default global bindings are only F1 (capture) and F3 (clipboard pin). No pin groups, Linux, Intel macOS, Windows ARM, cloud services, copied proprietary code or visual assets. Core models do not depend on platform window types. Implement end-to-end and record measured verification honestly.

## Operating Context
Close preferences without quitting; access commands from tray/menu bar. Permission failures must leave manual workflows usable. Platform tests are independent.

## Open Decisions
Name Simple Snip derives from repository (working name). Detailed visual choices are implementation decisions under the user's instruction to proceed immediately. No claims of release certification or unexecuted performance tests.
